# Лендинг груминг-салона «Гав&Мяу»

Одностраничный конверсионный сайт под заявки на груминг собак и кошек.
Один файл `index.html` — открывается двойным щелчком, работает без интернета и без сборщиков. Фотографии встроены внутрь файла (data-URI), поэтому превью не «ломается» в изолированном просмотрщике.

## Что уже готово

| № | Блок | Что внутри |
|---|------|-----------|
| 1 | Первый экран + УТП | Заголовок с УТП, 3 доказательства, кнопка «Записаться онлайн», карточки «ближайшее окно» и «4,9★», **мини-форма «перезвоните мне»** — номер подставляется в основную форму |
| 2 | Услуги и цены | Переключатель **Собаки / Кошки**, 8 карточек для собак и 6 для кошек (стрижки, мытьё, маникюр, линька, тримминг), доп. услуги, правила и наценки. Кнопка «Записаться» в карточке **сама подставляет услугу в форму** |
| 3 | Работы «до / после» | Три **интерактивных слайдера**: перетаскиваются мышью и пальцем |
| 4 | Отзывы | Рейтинг 4,9 + карусель из 6 отзывов со стрелками и свайпом |
| 5 | Мастера | 3 карточки с фото, опытом, специализацией и кнопкой «Записаться к мастеру» (подставляет имя мастера в форму) |
| 6 | Как проходит запись | 4 шага со сроками + кнопка записи |
| 7 | Форма заявки | Имя, телефон (с маской), питомец, услуга, мастер, дата, комментарий, согласие, валидация и экран «Заявка отправлена» со сводкой |
| 8 | Контакты и карта | Адрес, телефон, e-mail, часы работы, соцсети, схема проезда с кнопкой «Открыть в Яндекс.Картах» |

Дополнительно: полоса преимуществ после первого экрана, шапка с телефоном и CTA, мобильное меню, липкая нижняя кнопка «Записаться + позвонить» на телефонах, подвал с реквизитами, микроразметка schema.org (PetGroomer) для SEO.

В файле есть скрытая логика для конверсии: все кнопки ведут к форме, кнопки в карточках услуг и мастеров предзаполняют форму, телефон вводится маской, ошибки подсвечиваются, после отправки человек видит сводку и кнопки мессенджеров.

### Как заменить фото

1. Положите свои фото в `images/` с теми же именами: `hero.jpg`, `master1..3.jpg`, `before1..3.jpg`, `after1..3.jpg`.
2. Выполните в корне проекта:
   ```bash
   python3 build_images.py
   ```
   Скрипт сожмёт фото и вставит их в `index.html` вместо data-URI.
   Если фото не менять — ничего делать не нужно, сайт уже собран.

## Как подключить приём заявок (важно!)

Сейчас сайт в **демо-режиме**: заявка сохраняется только в браузере посетителя (в localStorage), чтобы вы могли проверить форму. Что заявки приходили вам — выберите один из вариантов.

**Вариант 1. Сервис форм (5 минут, без программиста)**
Зарегистрируйтесь на formspree.io, web3forms.com или getform.io, создайте форму и получите URL. В конце `index.html` найдите:

```js
const FORM_ENDPOINT = ''; // например: 'https://formspree.io/f/xxxxxxxx'
```

Вставьте свой URL — заявки начнут приходить на e-mail, в Telegram или в Google-таблицу (зависит от сервиса).

**Вариант 2. Свой обработчик / CRM**
Укажите адрес своего эндпоинта в той же строке. Сайт отправляет POST в формате JSON:

```json
{ "name": "Анна", "phone": "+7 (911) 223-34-45", "pet": "Собака",
  "service": "Модельная стрижка собаки", "master": "Алина Ковалёва — старший грумер",
  "date": "2025-10-05", "comment": "бишон, 3 года, боится фена",
  "consent": "on", "createdAt": "2025-10-01T10:00:00.000Z", "page": "https://..." }
```

**Вариант 3. Пока ничего не подключать**
Можно просто повесить на сайте телефон и мессенджеры — кнопки уже работают. Но форма без обработчика заявки не доставляет.

### Проверить форму после подключения
Откройте сайт, заполните поля тестовой заявкой, отправьте и проверьте, что запись пришла в ваш сервис. Ошибки отправки показывают alert с телефоном салона — посетитель в любом случае сможет дозвониться.

## Как заменить карту на настоящую Яндекс.Карту

В блоке 8 найдите комментарий с меткой `КАРТА`. Удалите блок `<svg class="map-svg"> … </svg>` и вставьте вместо него iframe из Яндекс.Конструктора карт:

```html
<iframe src="https://yandex.ru/map-widget/v1/?ll=30.356%2C59.934&z=16&pt=30.356,59.934"
        width="100%" height="100%" frameborder="0" style="border:0;position:absolute;inset:0"></iframe>
```

Координаты и метку возьмите в [Яндекс.Конструкторе карт](https://yandex.ru/map-constructor/). Сейчас вместо карты стоит лёгкая векторная схема — она мгновенно грузится и выглядит аккуратно даже без интернета.

## Как опубликовать

- **Быстро:** закиньте `index.html` (и папку `images/`, если не собирали через `build_images.py`) в любой хостинг — Timeweb, Beget, REG.RU, Netlify, GitHub Pages. Файл самодостаточный, базы и PHP не нужны.
- **Домен:** после публикации добавьте абсолютную ссылку на фото в `<meta property="og:image">`, чтобы превью сайта красиво выглядело в мессенджерах и соцсетях.
- **Аналитика:** вставьте счётчик Яндекс.Метрики перед `</body>`. Все кнопки уже размечены атрибутами `data-cta="header|hero|hero-quick|works|how|form"` — по ним можно настроить цели на клик. Цель «заявка отправлена» — показ блока `#formOk`.
- **Валидность:** HTML проходит проверку парности тегов, JS — без синтаксических ошибок и ошибок в консоли (проверено в headless Chromium на 1440 / 768 / 430 / 360 px; горизонтальной прокрутки нет).

## Загрузка на GitHub через браузер (без git и токенов)

Подходит, если не хочется возиться с git. Репозиторий: **github.com/PhoenixNeonDev/grouming_web**

1. Скачайте `gavmyau-landing.zip` и распакуйте его в любую папку.
2. Откройте https://github.com/PhoenixNeonDev/grouming_web
3. Нажмите **Add file → Upload files**.
4. Откройте распакованную папку, выделите **все** элементы (`index.html`, `README.md`, `build_images.py`, `.gitignore` и папку `images`) и перетащите их в область загрузки в браузере. Папка `images` перетаскивается целиком — структура сохранится.

   > Скрытый файл `.gitignore` видно только при включённом показе скрытых файлов (Windows: *Вид → Показать → Скрытые элементы*, macOS: `Cmd+Shift+.`). Если не получилось — загрузите без него, это необязательный файл.

5. Внизу страницы: **Commit changes** → оставьте вариант *Commit directly to the main branch* → подтвердите. Сообщение коммита можно вписать: `Лендинг груминг-салона «Гав&Мяу»: 8 блоков, интерактив, форма заявки`.
6. Проверьте: в репозитории должно появиться 15 файлов, а `LICENSE` остаться на месте. Заменить LICENSE не даст — в архиве его нет.

Ограничения GitHub на одну загрузку: до 100 файлов и до 25 МБ на файл. У нас 14 файлов, самый большой — `index.html` 812 КБ.

### Включить сайт (GitHub Pages)

*Settings → Pages → Source:* **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**. Через 1–2 минуты сайт откроется по адресу:

```
https://phoenixneondev.github.io/grouming_web/
```

Свой домен: *Settings → Pages → Custom domain* → впишите домен, а у регистратора добавьте CNAME на `phoenixneondev.github.io`. После публикации подставьте абсолютную ссылку на фото в `<meta property="og:image">` — превью сайта красиво выглядит в мессенджерах.

## Репозиторий уже инициализирован

Проект под git: ветка `main`, один коммит со всеми файлами (`e2ec933`), рабочее дерево чистое. Осталось подключить удалённый репозиторий и запушить.

### GitHub (HTTPS — проще всего)

1. Создайте **пустой** репозиторий: [github.com/new](https://github.com/new) → имя, например `gavmyau-landing`. Галочки «Add a README», «Add .gitignore», «Choose a license» **не ставьте** — файлы уже есть.
2. В папке проекта выполните:

```bash
git config user.name "Ваше Имя"
git config user.email "you@example.com"
git remote add origin https://github.com/ВАШ_ЛОГИН/gavmyau-landing.git
git push -u origin main
```

3. При пуше Git попросит логин и **токен, а не пароль**:
   GitHub → *Settings → Developer settings → Personal access tokens → Fine-grained tokens* → доступ к репозиторию `gavmyau-landing`, право **Contents: Read and write**.

### GitHub (SSH — если ключ уже настроен)

```bash
git remote add origin git@github.com:ВАШ_ЛОГИН/gavmyau-landing.git
git push -u origin main
```

> Примечание: команда `git remote add` привязывает репозиторий к вашему аккаунту — выполните её у себя на машине. В этой рабочей песочнице конфиг репозитория не сохраняется между сессиями, а сама история коммитов сохраняется.
